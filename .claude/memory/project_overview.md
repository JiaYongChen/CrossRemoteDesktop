UltraDesktop（极域桌面）是一个基于 Qt 6.9+/C++20 的跨平台远程桌面应用，客户端和服务端打包在同一个可执行文件中。

**Why:** 项目目标是提供低延迟的远程桌面体验，使用生产者-消费者管道架构处理屏幕捕获→编码压缩→网络发送。
**How to apply:** 所有架构决策需考虑低延迟（~20us 队列延迟目标）。当前为单客户端模式，未来可能扩展为多客户端。开发环境为 Windows（MSVC），但需考虑跨平台兼容性（macOS/Linux）。
