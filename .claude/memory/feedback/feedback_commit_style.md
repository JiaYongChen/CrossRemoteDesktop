Git commit 信息使用中文描述，常见格式为：`类型: 中文描述`

示例：
- `refactor: 移除多余的分号，清理代码`
- `refactor: 使用安全的字符串拷贝函数替换不安全的字符串拷贝，增强代码安全性`

**Why:** 项目已建立的 commit 风格，保持历史一致性。
**How to apply:** 提交时使用 `动词: 描述` 格式，中文书写。常用前缀：feat、fix、refactor、docs、test、chore。
