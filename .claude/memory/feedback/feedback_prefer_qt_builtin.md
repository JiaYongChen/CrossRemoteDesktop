在Qt6.9+技术框架内已包含的技术库，不要使用第三方库，必须使用Qt6.9+内置的库。但如果Qt内置库的功能无法完全满足开发所需的功能，则完全由第三方库替代，不做混合使用。

**Why:** 减少不必要的第三方依赖，保持项目依赖简洁，避免版本冲突和构建复杂度。Qt6.9+本身已经提供了丰富的模块（网络、多媒体、并发、OpenSSL集成、JSON、XML等）。当Qt内置功能不完整时（如Qt没有自签名证书生成API、没有通用zstd压缩API），混合使用Qt和第三方库反而增加复杂度，不如完全使用第三方库来覆盖该功能域。
**How to apply:** 在引入任何第三方库之前，先检查Qt6.9+是否已内置同等功能：
- 如果Qt已完整提供 → 必须使用Qt模块（如：网络用QtNetwork，JSON用QJsonDocument，并发用QtConcurrent）
- 如果Qt仅部分提供，无法完全满足需求 → 完全使用第三方库替代（如：Qt无自签名证书生成API → 完全用OpenSSL；Qt无通用zstd压缩API → 完全用zstd库）
